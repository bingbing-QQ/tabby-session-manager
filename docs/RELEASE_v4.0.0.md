# Tabby Session Suite v4.0.0

会话管理、按窗口控制日志、八套主题和端口转发诊断，支持中英文。

## 本版内容

- 会话和文件夹管理、收藏、最近记录清理、窗口识别、批量管理与撤销。
- 同名 SSH 多窗口日志独立控制，支持停止、继续写入、新文件和查看；日志路径仍可在 Tabby 设置中配置。
- 八套风格主题，可分别选择同步主界面和终端配色。
- 导入导出、选择性备份与恢复、转发规则交换和可选对象的端口检查。
- 原始阶段实现已替换，源码可独立构建；历史来源及适用许可证继续保留。

维护者已试用重写版并反馈正常。v4.0.0 相比已验证候选版只整理版本标识和发布内容，不新增功能。目标环境为 Windows + Tabby 1.0.238；其他系统和版本未验证。

完全退出 Tabby 后替换同名插件目录，保留配置、凭据和日志。详细安装、默认日志行为及兼容边界见项目 README 和 docs/INSTALL.md。

An independently maintained release combining session management, per-window logging, eight themes and selectable forwarding diagnostics. The maintainer reported no issues in the existing Windows / Tabby 1.0.238 environment. Configuration and feature compatibility are retained; other platforms and standard-install/uninstall/rollback scenarios remain separately documented acceptance items.

Independent community plugin, not an official Tabby product. Apache-2.0, with applicable upstream and historical MIT notices retained.
