# 兼容与验证 / Compatibility

目标验证环境：Windows / Tabby 1.0.238。维护者报告功能、双语、禁用启用、卸载重装、回滚至 4.0.4 再升级和 4.1.0-rc.1 npm 在线安装正常。此处区分维护者实机反馈与自动化证据：20 项脚本和四组浏览器测试使用模拟宿主，不是原生 Tabby 自动测试。

正式 4.1.0 已发布至 latest；维护者已报告 Tabby 插件库搜索、获取及重启后运行正常。其他平台、其他 Tabby 版本、所有代理与转发组合没有全面验证。元数据 >=1.0.238 是加载范围，不是未来兼容保证。

主题同步、密码保护和原生编辑器依赖宿主接口；宿主升级可能影响兼容。终端字体渲染仍由 Tabby 前端控制。端口检查只提供当前证据，不自动释放占用、删除 Windows 排除范围或修改系统服务。

详见 VALIDATION-v4.1.0.md、PRIVACY.md 和安装说明。
