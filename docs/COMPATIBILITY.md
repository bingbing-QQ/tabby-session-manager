# 兼容范围与数据行为

- Windows + Tabby 1.0.238：维护者在原环境试用重写版本，反馈未发现问题；未提交逐项安装/回滚记录。
- 自动验证：16 组独立脚本通过，另有 4 组 Windows Edge 模拟宿主界面检查。
- 标准用户插件目录全新安装、完整禁用/卸载/回滚和 npm 包安装：仍需单独记录验收。
- 其他 Tabby 版本、macOS、Linux：未实机验证。package.json 中的版本范围不是对全部未来版本兼容的承诺。

运行依赖宿主提供的 Angular、Tabby 和 Electron 服务，不在插件内安装另一份宿主模块。原生编辑器、SSH 转发 listener 检查及共享凭据删除保护依赖宿主接口/部分内部实现，升级 Tabby 时需要复测。

自动输出日志对新安装默认开启，输入记录默认关闭；已有用户设置保持。日志为明文，不提供自动轮转和保留清理；拥塞时有队列上限和丢弃提示。不要用于宣称不可篡改的合规审计。

主界面主题同步默认开启、终端配色同步默认关闭。可恢复原设置；系统文件窗口不跟随主题，其他全局主题插件可能产生样式冲突。不会修改用户的终端渲染前端。

共享凭据保护可能保留同目标密码，删除会话不等于彻底删除凭据。降级编辑器的凭据保存和会话配置保存不是单一事务，应核对保存失败后的实际状态。

转发检查不自动连接/重建隧道、不更改 Windows 排除范围、不结束占用进程。临时本地绑定成功不等于远端业务正常；远程转发和无法确认的运行状态会保留诊断边界。
