# 4.1.1 验证记录

## 版本来源

以维护者确认测试通过的 4.1.1-local.4 为基础。`verified-candidate.json` 保存该版本的运行文件指纹；正式版只更改 dist/index.js 第一行的版本注释，其他运行文件完全一致。`runtime-integrity.json` 校验正式运行文件。

## 自动化与本地安装

22 项功能/脚本验证及五组浏览器模拟检查覆盖原有功能、云目录元数据扫描、窗口折叠、字体大小和八套主题标签栏。目录测试拦截旧日志内容读取，验证扫描、刷新和展开期间零调用；模拟慢 I/O、共享缓存、切换竞态、错误和页面关闭。主题验证普通、悬停、当前标签、文字对比度、横线和装饰竖线移除、窄窗、多标签、侧边栏、关闭按钮和关闭同步后的恢复。

npm 实际打包后校验文件白名单，并在隔离目录安装与核对所有运行文件；不修改用户的实际 Tabby 插件目录。

## 实机证据与边界

维护者反馈本地测试通过并请求正式发布；此前也反馈 4.1.0 的原生插件库安装正常。实机及真实 OneDrive 的通过是维护者报告，不是独立原生自动化；不能推导所有云盘、网络盘、系统或宿主版本都已验证。

目录元数据查询不主动打开旧日志的数据流。操作系统和云同步客户端仍可因其自身策略下载文件；主动查看只交由系统打开对应文件。历史日志按文件名匹配存在同名/改名歧义，完整目录列表保留访问入口。

## 发布状态

本材料不执行发布。`prepare:release` 由维护者在已登录 npm 的环境运行，用来检查账号、维护权限、未发布版本、文件一致性和隔离安装；有效证明在 24 小时内才允许源目录发布。检查成功仍需手动执行 `npm publish`。GitHub 工作流只构建、验证和预览 npm 包，不发布 npm。
