# 重写范围与证据

版本：4.0.0-rc.1。稳定回退版本：3.6.0。

## 替换范围

- 原 SessionManagerService 的 130 个方法/构造入口在新源码中重新实现，包括生命周期、会话/目录操作、解析器、数据读写、主界面和菜单。维护源码位于 src/session-replacement.methods、src/session-ui.methods。
- 原日志引擎由 src/logger/logging-core.js 替换；日志设置页由 logging-settings.js 替换；logging.js 是新的 Tabby/Angular 接入层。
- 原主界面 CSS 由 src/session.css 替换。八套确认的主题颜色是兼容数据，保持原参数；不声称这些色值是独占设计。
- 后续追加的功能方法保存在 src/suite-features.methods；双语、宿主主题同步、对比度、共享凭据保护和转发检查保存在 src/shared/。它们属于最初归档之后的后续开发，继续使用新的基础实现。
- 构建仅读取 src，不读取原归档、work/review、原 logging.js 或任何 Manus 服务。发布包不夹带旧运行代码作为回退。

## 验证与限制

原会话类中 117 个非短小实现的规范化方法指纹与新实现均不同。原始代码不随指纹清单分发。指纹差异只能作为替换核对，不能单独证明独创性，也不能把重命名/排版差异当作重写依据。本次实际编写了新的方法实现、日志状态模型、设置渲染和样式。

16 组脚本覆盖行为合同与新增边界；4 组浏览器套件覆盖界面。测试保留原有行为断言；针对源代码排版、旧类提取方式和“日志文件必须完全不变”的旧检查，改为新模块加载/行为检查，因为这些内部实现正是此次替换对象。

已通过：基础 13 组、增强功能 22 组、真实日志文件写入与旧日志识别、日志输入开关及 ANSI 分块、映射复位/失败恢复、连接启动期记录、ConfigProxy 持久化、8 套主题、诊断、最近记录独立清理、编号及焦点跟随。

尚未在真实 Tabby/Electron 中运行候选版本；Windows Edge 模拟宿主不能覆盖 Angular 宿主编译、真实 SSH 认证、操作系统权限和安装路径的全部差异。该描述对应初次 rc 自动验证阶段。当前已根据维护者试用结果准备 4.0.0；仍保留 private=true 防止资料准备期间误发布，后续 npm 验收单独完成。

## 数据兼容

| 项目 | 处理 |
| --- | --- |
| sessionManager / autoSessionLogger | 保持配置键与原有默认设置；不重置语言、主题或路径 |
| Profile ID、目录 ID | 不批量重建，编辑/移动/撤销按唯一 ID |
| session-log-manager 设置页 ID | 保留 |
| 日志目录映射 | 保留原 APPDATA/Tabby/tabby-session-log-manager.json 与主目录映射位置；新映射写入采用临时文件加重命名 |
| 旧日志 | 根据 Profile ID 头、旧 tag 或明确的旧文件命名识别；不改写历史文件 |
| 日志文件 | 保留日期时间_会话名_短ID，独占创建，重连新文件、同次连接续写 |
| 备份 | 保留 schemaVersion 1/2 和密码/私钥排除边界 |
| 端口规则交换 | 保留 tabby-session-manager-port-forwarding 格式、schemaVersion 1 |
| 自动日志/输入记录 | 保留原默认值和已有偏好；自动日志默认开启，输入记录默认关闭 |
